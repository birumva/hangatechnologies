1. What cookies and similar technologies are

Cookies are small text files placed on your device by a website. "Similar technologies" include local storage and session storage, which let a website save information in your browser without setting a cookie. These technologies can be used to make a site work, remember your preferences, or measure how it is used.

2. What this website uses today

This website is built to work with essential technologies only. It does not set advertising cookies, and it does not currently use analytics or tracking cookies. Because of this, we do not display a cookie consent banner. If that changes, we will add a consent mechanism and update this notice first.

4. Optional cookies

Optional cookies are not currently used. If we introduce them in future, they would fall into these categories and would only be set with your consent:

  • Analytics cookies — to understand which pages are visited and how the site performs, so we can improve it. We would favour privacy-respecting tools with IP anonymisation and no cross-site tracking.
  • Functional cookies — to remember additional preferences, such as a language choice.

We do not intend to use advertising or social media tracking cookies on this website.

5. Third-party services

6. How to control cookies and storage

You can control and delete cookies and local storage through your browser settings. Most browsers allow you to block cookies entirely, block third-party cookies, or clear stored data for a specific site. Blocking essential storage on this site will only affect the saved theme preference. Instructions for common browsers:

  • Chrome: Settings → Privacy and security → Cookies and other site data
  • Firefox: Settings → Privacy & Security → Cookies and Site Data
  • Safari: Preferences → Privacy → Manage Website Data
  • Edge: Settings → Cookies and site permissions

7. Changes to this notice

If we change the technologies used on this website, we will update this notice and, where consent is required, ask for it before any optional cookies are set. The "last updated" date shows the current version.
